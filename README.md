# Smart Bug Tracker & Analyzer

A software bug tracking and analysis system built using Python, Streamlit, SQLite, Pandas, and FastAPI.

## Features

- Create and manage software bugs
- Automatic bug category detection
- Automatic severity detection
- Bug status management
- Search and filter bugs
- Dashboard with bug statistics
- Status, category, and severity charts
- SQLite database
- REST API using FastAPI
- CRUD operations through API

## Technology Stack

- Python
- Streamlit
- SQLite
- Pandas
- FastAPI
- Uvicorn
- SQL
- REST API

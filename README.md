# 🐞 Smart Bug Tracker & Analyzer

A web-based software bug tracking and analysis system developed using Python, Streamlit, SQLite, Pandas, and FastAPI.

The application helps users report, manage, search, analyze, and monitor software bugs through an interactive dashboard and REST API.

## 🚀 Features

- 🐞 Create and manage software bugs
- 🤖 Automatic bug category detection
- 🚨 Automatic severity detection
- 🔄 Bug status management
- 🔎 Search and filter bugs
- 📊 Interactive bug dashboard
- 📈 Status, category, and severity charts
- 🗄️ SQLite database for data storage
- ⚡ FastAPI REST API
- 🔧 CRUD operations through API
- 📖 Swagger API documentation

## 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| Python | Application logic |
| Streamlit | Web interface |
| SQLite | Database |
| Pandas | Data analysis |
| FastAPI | REST API |
